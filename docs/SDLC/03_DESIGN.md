## 1. Принципы дизайна

| # | Принцип | Как реализован |
|---|---|---|
| 1 | **Одна задача — один экран** | Генерация, сохранение и просмотр разделены на две карточки |
| 2 | **Мгновенная обратная связь** | Длина и чекбоксы пересчитывают пароль на `input`, без кнопки |
| 3 | **Без сюрпризов** | Любое разрушительное действие подтверждается диалогом |
| 4 | **Ничего не уходит на сервер** | Это заявлено прямо под таблицей — снимает главное сомнение пользователя |
| 5 | **Доступность по умолчанию** | Клавиатурная навигация, aria-атрибуты, контраст ≥ 4.5:1 |

## 4. Состояния интерфейса

| Состояние | Визуальное решение | Управление |
|---|---|---|
| Пустое хранилище | Серая плашка «Нет сохранённых паролей» | `role="status"` |
| Пароль скрыт | `••••••••••••••••`, кнопка 👁️ | `aria-label="Показать пароль: …"` |
| Пароль раскрыт | Код моноширинным, кнопка 🙈 | тот же `aria-label` сменён |
| Есть результат поиска | Счётчик «Найдено: N из M» | `aria-live="polite"` |
| Успех | Зелёный тост снизу, 3 сек | `role="status"` |
| Ошибка | Красный тост снизу | `role="alert"` |
| Опасное действие | Модальный диалог поверх затемнения | `role="alertdialog"`, Escape = отмена |
| Фокус с клавиатуры | Обводка `3px` `--color-primary` + отступ 2 px | `:focus-visible` |
| Сниженная анимация | Все переходы → 0.01 ms | `prefers-reduced-motion` |

## 5. Типографика и сетка

- **Сетка карточек:** одноколоночная, максимум 1000 px, зазор 24 px.
- **Опции символов:** `grid-template-columns: repeat(auto-fit, minmax(210px, 1fr))`
  → 4 колонки на десктопе, 1 колонка ≤ 768 px.
- **Таблица:** на ≤ 768 px уменьшается кегль, действия переносятся в столбик,
  название обрезается `text-overflow: ellipsis` (макс. 130 px).
- **Табличные числа:** даты моноширинным не используются — применён `ru-RU` формат
  `Intl` короткой записью (`20.10, 15:34`), чтобы колонка не «прыгала».

## 6. Доступность (WCAG 2.1 AA)

| Требование | Реализация |
|---|---|
| 1.3.1 Информация и отношения | `<fieldset>/<legend>` для наборов, `<th scope="col">`, `<caption>` у таблицы |
| 1.4.3 Контраст текста | `--color-text` на белом = 12.4:1; мутный текст 4.8:1 |
| 1.4.11 Неконтрастный контент | рамки кнопок ≥ 3:1, индикатор не единственный носитель смысла (есть текст) |
| 2.1.1 Доступность с клавиатуры | все кнопки — `<button>`, узлы диаграммы `tabindex="0"` + `Enter/Space` |
| 2.4.3 Порядок фокуса | порядок в DOM совпадает с визуальным |
| 2.4.7 Видимый фокус | `:focus-visible` с обводкой |
| 3.3.2 Подписи полей | `label for` у всех полей, скрытые подписи для иконок-кнопок |
| 4.1.2 Имя / роль / значение | `aria-pressed`, `aria-selected`, `aria-valuenow/valuetext`, `aria-label` |
| 4.1.3 Статусы | `aria-live` у тоста, счётчика и поля вывода |
| 2.3.3 Анимация от движения | `prefers-reduced-motion` |

**Проверено:** автотесты DOM (TC18–TC22) и визуальный просмотр скриншотов
на 320 / 768 / 1920 px.

## 7. Решения по UX, которые были приняты осознанно

1. **Уведомления вместо `alert()`.** Блокирующие всплывающие окна роняют
   пользовательский поток; тосты не перехватывают фокус.
2. **Модальный диалог вместо `confirm()`.** Стилизуется под дизайн-систему,
   доступен с клавиатуры, закрывается по Escape.
3. **Живая генерация при изменении слайдера.** Кнопка «Сгенерировать» оставлена
   для явного действия и для клавиатурной навигации.
4. **Пароль в таблице скрыт по умолчанию.** Экран может быть наведён на
   публичном месте — раскрытие должно быть осознанным.
5. **Энтропия показана числами.** Субъективное «сильно» подкреплено
   измеримыми битами — пользователь видит, на чём основана оценка.

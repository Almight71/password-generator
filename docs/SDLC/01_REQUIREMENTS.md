## 1. Общее описание продукта

Статическое веб-приложение (без серверной части), которое:

1. генерирует криптостойкие пароли с настраиваемыми параметрами;
2. сохраняет их в браузере пользователя (localStorage);
3. показывает сохранённые записи в виде таблицы с поиском и управлением;
4. оценивает силу пароля и показывает запас энтропии в битах.

**Целевая аудитория:** пользователи, которым нужны надёжные пароли без регистрации
и без передачи данных на сторонний сервер.

**Границы продукта (out of scope):**

- серверное хранение и синхронизация между устройствами;
- шифрование базы мастер-паролем (запланировано в v1.1, см. [07_MAINTENANCE.md](07_MAINTENANCE.md));
- генерация паролей из мнемонических фраз;
- менеджер паролей с автозаполнением форм.

### 2.1. Пороги уровней силы пароля

Уровень определяется по энтропии `bits = length × log2(poolSize)`,
где `poolSize` — сумма размеров реально использованных классов символов.

| Уровень | Порог, бит | Цвет индикатора | Бейдж в таблице |
|---|---|---|---|
| Очень слабый | `0 ≤ bits < 28` | `#b71c1c` | weak |
| Слабый | `28 ≤ bits < 44` | `#e53935` | weak |
| Средний | `44 ≤ bits < 64` | `#fb8c00` | medium |
| Сильный | `64 ≤ bits < 88` | `#43a047` | strong |
| Очень сильный | `bits ≥ 88` | `#1b5e20` | strong |
| Пустой пароль | — | не заполняется | — |

Ориентиры: 16 символов из полного алфавита (88 знаков) → **103.4 бита** → «Очень сильный».

### 2.2. Границы ввода

| Параметр | Минимум | Максимум | Поведение вне диапазона |
|---|---|---|---|
| Длина пароля | 4 | 32 | ограничивается (clamp); нечисловое значение → 16 |
| Название записи | 2 символа | 100 символов | отклоняется с сообщением об ошибке |
| Наборы символов | 1 набор | 4 набора | последний нельзя снять |

## 4. Use cases

### UC-1. Создание пароля

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Пользователь открывает `index.html` | Пароль уже сгенерирован, индикатор силы заполнен |
| 2 | Меняет длину слайдером | Значение и пароль обновляются на лету |
| 3 | Снимает лишние чекбоксы | Алфавит уменьшается, сила пересчитывается |
| 4 | Пытается снять последний чекбокс | Чекбокс возвращается, показывается ошибка |
| 5 | Нажимает «Сгенерировать» | Новый пароль отображается в поле вывода |

**Альтернативный сценарий:** пустой набор символов → сообщение «Выберите хотя бы одну опцию символов», поле очищается.

### UC-2. Сохранение пароля

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Вводит название в поле | Подсказка о минимальной длине |
| 2 | Нажимает «Сохранить» или Enter | Запись появляется в таблице, поле очищается |
| 3 | Перезагружает страницу | Запись на месте (данные из localStorage) |

**Обработка ошибок:** пустое название, 1 символ, 101 символ, отсутствующий пароль → уведомление с причиной, фокус возвращается в поле.

### UC-3. Поиск и управление

| Шаг | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Вводит часть названия | Таблица фильтруется мгновенно |
| 2 | Очищает поле | Возвращаются все записи |
| 3 | Нажимает 👁️ | Пароль раскрывается, кнопка меняет подпись и `aria-label` |
| 4 | Нажимает 📋 | Пароль копируется, показывается уведомление |
| 5 | Нажимает 🗑️ | Открывается модальный диалог |
| 6a | Нажимает «Отмена» | Запись остаётся |
| 6b | Нажимает «Удалить» | Запись удаляется, список обновляется |

### UC-4. Очистка хранилища

Пользователь нажимает «Очистить всё» → подтверждает в диалоге → таблица показывает пустое состояние. Отмена не изменяет данные. Если хранилище уже пусто, выводится информационное уведомление вместо диалога.

## 5. Ограничения и допущения

| Тип | Описание |
|---|---|
| Ограничение | Данные живут в одном браузере и одном профиле; очистка данных сайта удаляет пароли |
| Ограничение | localStorage не защищён: любой скрипт с тем же origin может прочитать записи |
| Ограничение | Объём хранилища ~5 МБ; при переполнении выводится понятная ошибка |
| Допущение | Пользователь имеет включённый JavaScript |
| Допущение | Поддерживается браузер с `crypto.getRandomValues` (все актуальные) |
| Допущение | Clipboard API доступен при открытии по HTTPS/localhost; на `file://` используется резервный путь |

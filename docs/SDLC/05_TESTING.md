## 4. Ключевые проверки

### 4.1. Криптостойкость (TC7)

- 1000 значений `secureRandomInt(7)` лежат строго в `[0, 6]`;
- хи-квадрат для 9000 выборок с 3 равными исходами: `χ² < 16` при критическом
  значении 13.8 (df=2, p=0.001) — смещение не обнаружено;
- `0`, отрицательные и дробные аргументы бросают `Error`.

Это важно: стандартный `Math.floor(Math.random() * n)` даёт лёгкое смещение,
недопустимое для паролей.

### 4.2. Гарантия состава (TC5, TC6)

В 200 подряд сгенерированных паролях (все 4 набора включены) каждый раз
присутствует минимум один символ каждого класса. В 100 паролях «только цифры»
ни одного постороннего символа.

### 4.3. XSS (TC14, TC20)

```
Ввод:        <img src=x onerror=window.__xss=1>&"`'
escapeHtml:   &lt;img src=x onerror=window.__xss=1&gt;&amp;&quot;&#39;&#96;
```

В jsdom запись с враждебным именем принудительно кладётся в хранилище
(минуя валидацию — как если бы JSON скомпрометирован), после чего проверяется,
что в DOM **нет** ни `<img>`, ни `<script>`, а `window.__xss` остался `undefined`.

### 4.4. Устойчивость к повреждённым данным (TC17)

| Содержимое `localStorage` | Ожидаемое поведение | Факт |
|---|---|---|
| `это не JSON {` | `[]`, приложение работает | ✅ |
| массив с посторонним объектом | валидные записи сохранены, мусор отброшен | ✅ |
| `{...}` вместо массива | `[]` | ✅ |

## 6. Известные ограничения тестов

1. **Clipboard API** не покрыт автотестами (нет в jsdom) — ручной сценарий M1.
2. **Реальные браузеры** (Chrome/Safari/Edge) не прогоняются автоматически —
   используется только Firefox headless; совместимость обоснована
   отсутствием экзотических API (см. NFR4 в [01_REQUIREMENTS.md](01_REQUIREMENTS.md)).
3. **Нагрузочные тесты** не проводились: объём данных — десятки записей,
   а не тысячи; при появлении категорий и экспорта нагрузочный сценарий
   будет добавлен (см. [07_MAINTENANCE.md](07_MAINTENANCE.md)).
4. **Покрытие строк** не измеряется инструментально: проект без сборщика и без
   инструмента покрытия в стеке; вместо этого все ветвления логики
   закреплены явными кейсами (17 unit-тестов на 5 модулей).
